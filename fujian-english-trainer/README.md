# 福建专升本 · 英语翻译训练小程序

面向福建专升本英语考试的翻译练习微信小程序。纯本地运行，**无需后端、无需联网**，导入微信开发者工具即可跑通，手机上可直接真机预览。

## 功能对照需求

| 需求 | 实现 |
| --- | --- |
| 1. 考纲题库、中英互译 | `data/words.js` 64 个核心考纲词（4 个难度档）；`data/sentences.js` 50 个翻译句，每句标注考点词汇与解析，出题时随机英译汉/汉译英 |
| 2. 选择题 + 手动输入双模式 | 每题作答前可切换。选择题四选一（干扰项取相邻难度句子译文）；手动输入由 `utils/judge.js` 本地判分：汉译英=关键词覆盖率(55%)+编辑距离相似度(45%)，英译汉=中文 n-gram 覆盖率；分为"正确 / 基本正确 / 错误"三档，并展示参考答案、解析和考点词汇 |
| 3. 自适应学习 | 每词掌握度 0-5 级：答对 +1、答错 -2、半对不变。抽题权重 `[6,5,4,2.5,1,0.15]` 随掌握度衰减——熟练词出现频率逐步降低直至接近淘汰；未掌握/新词权重最高 |
| 4. 难度递进 | 用户等级由已掌握词数决定（≥10→Lv2，≥25→Lv3，≥45→Lv4）。抽题时熟词占比不足一半的句子降权（保证可理解），每句新词数随等级放宽（Lv1 至多1个 → Lv4 至多3个），可接触比当前等级高一档的句子形成坡度 |
| 5. 界面模块 | 首页（每日练习/进度/连击）、错题（自动收录、重练答对自动移出）、词汇（掌握度筛选+进度条）、统计（累计/正确率/近7天柱状图/词汇分布/重置数据） |
| 6. 语音能力 | 题目加载自动朗读题干；英文题干/参考答案支持点读（点击单词弹词义卡并播放发音）；作答后自动朗读参考答案；`utils/tts.js` 统一封装（InnerAudioContext + 有道语音接口） |

## 如何在手机上运行（约 5 分钟）

1. 电脑安装 **微信开发者工具（稳定版）**：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开工具 → 导入项目 → 选择本目录 `fujian-english-trainer` → AppID 一栏点"使用测试号"（项目已内置 `touristappid`，通常无需改动）
3. 编译通过后即可在模拟器中使用
4. **真机运行**：点工具栏「预览」→ 用手机微信扫码 → 即可在手机上完整体验（学习记录存在手机本地）
   - 语音功能（自动朗读/点读）走在线语音接口：开发者工具中勾选「详情 → 本地设置 → 不校验合法域名」即可；真机预览时在预览页右上角菜单开启「调试模式」；正式发布需在 mp 后台把 `https://dict.youdao.com` 加入 **downloadFile 合法域名**
5. 想正式发布给同学用：需要注册小程序 AppID（个人主体免费），在 mp.weixin.qq.com 注册后替换 project.config.json 里的 appid，再点「上传」提交审核。本应用无网络请求、无用户隐私接口，审核通常很顺利

## 当前边界与可扩展点（如需要可以告诉我）

- **句子是预置库而非 AI 生成**：目前 50 句覆盖全部 64 词。可按同样格式往 `data/sentences.js` 加句，引擎自动纳入抽题；也可以接入云开发 + 大模型 API 实现真正的"动态造句 + AI 判分"，那需要 AppID 和云环境
- **输入判分是启发式**（关键词+相似度），对意思对但表达差异大的答案可能误判；点击"基本正确"档已做缓冲，进阶可换 AI 判分
- **词库 64 词**：覆盖考纲高频词，可按考纲词汇表扩充到数百词，只需在 `data/words.js` 追加条目并配句
- 成就系统、打卡分享、单词发音（需音频 CDN 域名白名单）等都可以继续加

## 学习数据说明

全部数据存于 `wx.Storage`（key: `fj_eng_state_v1`），卸载小程序或点统计页"重置学习数据"才会清除。
