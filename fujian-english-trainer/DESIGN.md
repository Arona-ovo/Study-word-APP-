# 升本英语翻译 · UI 设计方案

> 设计目标：备考场景下的「专注、可信赖、有正反馈」。语言学习类产品需要高频使用不疲劳，
> 因此整体采用低饱和背景 + 单一品牌绿作为行动色，用琥珀色承载激励信息（连击、熟悉度），
> 用红/绿语义色承载答题反馈，让用户在 3 秒内理解当前状态。

## 一、设计原则

1. **行动唯一**：每个屏幕只有一个主按钮（品牌蓝填充），其余均为次级幽灵按钮或文字按钮
2. **状态即颜色**：正确=品牌蓝、错误=红、半对/激励=琥珀、熟悉=紫，全局语义一致，不学新规则
3. **拇指可达**：核心操作（开始练习、下一题、提交）全部位于屏幕下半区，触控目标 ≥ 88rpx
4. **内容优先**：题干字号最大、对比最强；辅助信息（标签、提示）降两级灰度
5. **伙伴感**：看板娘"阿罗娜"（蓝发光环 Q 版形象，原创插画）出现在启动封面与首页，强化陪伴式学习氛围

## 二、设计令牌（Design Tokens）

### 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| brand-600 | `#2E6BFF` | 主按钮填充、进度条、选中态（白字仅用于大字号/组件，符合 WCAG AA） |
| brand-700 | `#1D4FD8` | 文字链接、按下态（白底对比度 7:1） |
| brand-300 | `#A9C3FF` | 主按钮禁用态 |
| brand-50 | `#EBF1FF` | 正确反馈底色、标签底色 |
| accent-500 | `#F79009` | 连击、熟悉、半对反馈 |
| accent-700 | `#B54708` | 琥珀底上的文字（对比度 4.6:1） |
| accent-50 | `#FEF3E0` | 琥珀标签底色 |
| error-500 | `#E5484D` | 错误反馈 |
| error-50 | `#FDECEA` | 错误底色 |
| violet-500 | `#7C3AED` | "熟悉"等级（与品牌蓝区分） |
| violet-50 | `#F1ECFF` | 紫色标签底色 |
| ink-900 | `#17201A` | 主文本（白底对比度 15:1） |
| ink-500 | `#5A6560` | 次级文本（对比度 6.5:1） |
| ink-300 | `#98A19B` | 提示文本（仅用于非关键信息） |
| bg | `#F4F6F4` | 页面背景（微绿灰，护眼） |
| line | `#E7EBE7` | 分隔线、轨道 |

### 字体尺度（简约高级 · 5 级收敛）

| 级别 | 规格 | 用途 |
| --- | --- | --- |
| Display | 48-52rpx / 600 / 字距 1-8rpx | 封面应用名、统计大数字、练习总分 |
| Title | 34-40rpx / 600 / 字距 1-2rpx | Hero 标题、卡片标题、结果标题 |
| Body | 28-30rpx / 400-500 / 行高 1.6 | 选项、正文、释义 |
| Caption | 24rpx / 400 / 字距 1-2rpx | 标签、辅助信息 |
| Micro | 22rpx / 400 | 提示语（仅非关键信息） |

**字重纪律**：全局只用 400 / 500 / 600 三档，禁用 700 以上的"重黑"；靠留白与字距建立层级，而非加粗。
**中英混排**：英文题干、单词、点读弹窗使用衬线体 `Georgia, "Times New Roman", "PingFang SC", serif`，
中文自动回退 PingFang——衬线英文带来书卷气，是"高级感"的核心手法。
**全局字距**：正文 0.5rpx、标题 1-2rpx、封面大标题 8rpx（拉字距是中文排版显高级的最快路径）。

### 间距 / 圆角 / 阴影（布局节奏）

- 间距：8 的倍数体系 —— 页面边距 28-32、卡片内边距 40×36（比之前更松）、卡片间距 24、列表项间距 18
- 圆角：卡片 24、选项/输入卡 20、标签与按钮 999（胶囊）
- 分割：**发丝边框 `2rpx solid #eff2f5` + 极浅投影 `0 2rpx 8rpx rgba(23,32,26,.03)`**，卡片扁平克制，
  不用多层重影；阴影只保留在 Hero 与封面的品牌色投影上（`rgba(13,40,120,.25-.35)`）作为视觉焦点

## 三、组件规范

### 按钮
- Primary：brand-600 填充 + 白字 + 胶囊，高度 96rpx，禁用态 `#A9DCC2`（仍可辨识为按钮）
- Ghost：白底 + brand-700 描边文字，用于"返回首页"等次级动作
- 文字按钮（重听、重置）：brand-700 描边小胶囊 / ink-300 纯文字

### 答题选项
- 默认：白卡 + 2rpx 透明描边（占位防跳动）+ 字母圆形徽标
- 按下：`hover-class` 浅绿底 `#F0FAF4`
- 正确：brand-600 描边 + brand-50 底 + 徽标反白
- 错误：error-500 描边 + error-50 底 + 徽标反白
- 反馈不依赖颜色单一通道：同时改变描边、底色、徽标三处

### 标签（Tag）
语义四色：绿=方向/成功、灰=难度、琥珀=错题/学习中、蓝=熟悉；22rpx 字 + 999 胶囊

### 进度与图表
- 进度条：14rpx 高圆角轨道 + brand 渐变填充（90deg, #12B76A→#0E9F50）
- 柱状图：渐变柱 + 顶部圆角，空数据用浅灰柱占位（不隐藏，保持 7 天节奏感）

### 点读弹窗
居中卡片 + 45% 黑遮罩；单词 44rpx 加粗居视觉中心，词义次之，"再听一次"为唯一行动按钮；
点击遮罩关闭，符合微信用户习惯

## 四、页面要点

- **封面**：全屏品牌蓝渐变（160deg, #4F8CFF→#1D4FD8）+ 装饰圆斑；看板娘置于白边圆形相框居中，下接应用名与口号；"开始学习"为白底蓝字胶囊按钮，点击进入 tabBar 首页
- **首页**：品牌蓝渐变 Hero（135deg, #4F8CFF→#1D4FD8，饰以半透明圆斑），右上角嵌看板娘圆形头像；下方"每日练习"卡是唯一主动作；三宫格入口等宽分布
- **练习页**：顶部细进度条（完成感）；题干卡内标签行右置"重听"；模式切换为分段控件（Segmented Control），作答后锁定降透明度；结果区用色彩标题 + 灰底解析块 + 考点词 chips，主按钮"下一题"贴底
- **错题页**：顶部行动卡"开始错题重练"为主按钮；列表项内"你的答案/参考答案"红绿对照
- **词汇页**：顶部四格总览 + 横向滑动筛选胶囊（选中=实心绿）；每词含掌握度细进度条
- **统计页**：2×2 指标卡大数字；近 7 天渐变柱状图；分布条形四语义色

## 五、无障碍与实现说明

- 正文对比度 ≥ 4.5:1（ink-900/ink-500），大按钮白字 ≥ 3:1；琥珀底上用 accent-700 文字
- 所有可点区域 ≥ 88rpx 高；点读单词带虚线下划线 + 文字提示"点击单词可查看词义"
- 实现：WXSS 中直接硬编码令牌值（部分基础库对 CSS 变量支持不稳），本文件为唯一令牌来源；
  交互动效用 transition ≤ 300ms，不使用大面积动画，兼顾低端 Android 机性能
