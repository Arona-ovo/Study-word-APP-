## 修复「图片淡化无效」+ 新增图片模糊
- 根因：`page::before`（蒙版层）是 z-index:-1，而 `page` 不是层叠上下文 → 负 z-index 子元素被上移到根层叠上下文，
  绘制顺序落在 `page` 自身背景**之前**，被 page 的背景图完全盖住。修复：`page { position: relative; z-index: 0 }`
  （注意不能用 `isolation: isolate`，那会创建 backdrop root，玻璃卡片的 backdrop-filter 就采样不到背景了）
- 模糊：蒙版层加 `backdrop-filter: blur(var(--app-bg-blur, 0px))`，0-24px 可调（`setBlur`，钳制 0/24）；
  不支持 backdrop-filter 的端退化为只有淡化
- 新增 settings.theme.bgBlur；设置页外观栏加「图片模糊」滑杆（仅在有背景图时显示）

## 动画与跟手的两处调优
### 设置页胶囊展开动画（修复）
- 病因：内容 v-if 瞬间撑到全高，而 border-radius 还在 999rpx→32rpx 过渡的中间态
  → 出现"已经很高但四角仍是巨圆"的畸形卡片（这就是用户说的"动画有问题"）
- 处理：圆角改**瞬间切换**（去掉 transition）；展开感交给 .sec-body 的 CSS 关键帧
  max-height 0→4000rpx + padding-bottom 0→40rpx + opacity + translateY(-8rpx)，
  260ms cubic-bezier(.22,.61,.36,1)（起步快→视觉约 200ms 到位，剩余时长无可见变化）
- 收起走 v-if 直接移除（零延迟最跟手）；加了 prefers-reduced-motion 直接就位
- 关键技巧：新创建元素用 animation 而非 transition，无需"先渲染起点再改值"的两帧 JS

### 底部导航栏不跟手（真 bug + 时长调优）
- 真 bug：sync() 被调用两次（mounted + 页面 onShow），第二次会 `indIndex = target` 直接到位，
  把正在跑的滑动掐断 → 表现就是"有时候滑、有时候跳"。
  修：加 __sliding 记录"正在滑向哪里"，重复 sync 直接 return；哨兵用 -1（0 会和首页下标撞车）
- 新增 pending：点击瞬间先把高亮切过去，不等新页面挂载；模板改用 activeKey = pending || current
- 时长：指示胶囊 320→220ms（cubic-bezier(.22,.61,.36,1)）、按下回弹 180→120ms、scale .9→.94、
  hover-stay-time 70→40ms、文字变色 240→140ms、图标弹跳 360→240ms
- 新增 _tools/check-tabbar.js：抽出 .vue 的 script 用 new Function 跑（export default → const COMP，
  并暴露模块级 lastIndex），用受控定时器回归"二次 sync 不打断"等 8 组；全绿

## 修 bug：AI 补词后按回车 → 结果变成 "Object"
现象：搜一个本地没有的词，AI 生成并展示正常；按手机键盘回车后，搜索结果变成单词 "Object"。
根因：键盘回车在某些端给的不是字符串，float-navbar 直接 `this.$emit('search', e.detail.value)`，

1. `float-navbar.pickValue(e)`：`detail` 是字符串 / {value} / {text} 都能抠出来，拿不到就退 `this.value`
2. `home.pickText(v)`：同理，且 `onSearchInput` 用 `JUNK_TEXT=/^\[object\s/i` 直接拦掉
3. `home.aiLookup` 加 `WORDISH=/^[\p{L}\p{N}][\p{L}\p{N}\s'’\-·]{0,39}$/u`：不像单词就不问 AI（防再写脏数据）
另加 `wordbook.purgeJunkWords()`：启动时清掉所有词书里以 `[object` 开头的词条（幂等，
不影响正常单词 "object"），App.vue onLaunch 调一次。

## 设置页胶囊两处变形（AI）

  （数据与账号）没人占位，箭头就贴上去了。修：`.sec-name { flex:1 }` 让标题自己占满，箭头恒靠右
